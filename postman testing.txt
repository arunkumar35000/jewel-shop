[API-13] Stripe Payment Cancellation Callback
Method  : GET
URL     : http://172.21.239.226:8000/api/v1/payment/stripe/cancel/?session_id=cs_test_sample
Headers : Accept: application/json
Expected: 200 OK (Records cancelled transaction attempt and redirects to checkout)

[API-14] Stripe Webhook Event Listener
Method  : POST
URL     : http://172.21.239.226:8000/api/v1/payment/stripe/webhook/
Headers : Content-Type: application/json
          Stripe-Signature: t=1612345678,v1=abcdef...
Body (raw JSON):
{
  "id": "evt_test_webhook_001",
  "type": "checkout.session.completed",
  "data": {
    "object": {
      "id": "cs_test_sample",
      "payment_status": "paid",
      "amount_total": 16999900,
      "currency": "inr",
      "metadata": {
        "order_number": "GJ-20261110-B4D252"
      }
    }
  }
}
Expected: 200 OK (Idempotently reconciles Payment record and marks order PAID)

[API-15] Payment Transactions Ledger API (Admin API)

Expected: 200 OK (List of all payment transactions, Stripe txn IDs, card brands, timestamps)
